# Data

The source dataset is not committed to this repository.

**Contents:** ~114,000 EV charging session records from Bengaluru, August–November 2024, joined against station metadata, customer demographics, vehicle specifications, and project-level financial records for 98 candidate sites.

**Source:** Provided as part of the WsCube Tech Data Analytics Mentorship Programme (Milestone Project 1).

**Note:** November represents a partial month of coverage. Month-over-month trend analysis in the dashboard should be read to October.
